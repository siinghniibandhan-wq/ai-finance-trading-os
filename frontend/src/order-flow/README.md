# Order Flow workspace

The Financial OS navigation exposes **Order Flow** as a separate workspace alongside the existing **Markets** page. The existing Markets workspace remains unchanged.

## Phase 1 preview

The integrated workspace includes the futures-flow chart, sector rail, bullish/bearish ranked lists, instrument details, support/resistance, option open-interest profile, conviction-check presentation, and the source project's 217-instrument universe catalogue.

The current data provider is a deterministic simulated preview. It is labelled as simulated in the interface and must not be interpreted as live market data or trading advice.

## Phase 2 — not yet implemented

Live futures prices and open interest, contract-month aggregation, full option-chain data, strike-wise CE/PE open interest, historical OI comparisons, streaming updates, and m.Stock gateway configuration are deferred. They require a separately reviewed implementation and explicit approval before any production, AWS, credential, or broker changes.
